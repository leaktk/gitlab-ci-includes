# GitLab CI/CD Includes

Configurations for using LeakTK components within GitLab CI/CD pipelines.

## Overview

As this repository is hosted on GitHub, the configurations provided here are
intended to be consumed by GitLab pipelines using the
[include:remote](https://docs.gitlab.com/ci/yaml/#includeremote) keyword,
referencing the raw file URLs.
